Reset Instances

Deletes everything SwarmDialer created on that PBXware instance — trunk, tenant & tenant package for Multi-Tenant editions, or trunk & extensions otherwise — and removes it from SwarmDialer. Does not affect anything on the other (peer) instance. Tenant deletion can take several minutes.

Reset SwarmDialer

Deletes SwarmDialer's saved configuration and restarts the GUI, back to a fresh-deployment state. Does not touch anything on PBXware — reset the instances above first if you want those cleaned up too.

Full Reset

Resets every connected instance, then resets SwarmDialer itself. This cannot be undone.
